# data_public/

Open data of the Comune di Savona (SIT, geoportal), downloaded 2 Nov 2026, licence CC BY 4.0. Used only as an independent
check of the radar detections (municipal sewer and storm-water pipes cross the surveyed streets; positional accuracy of
the records is not stated by the publisher). Not gas pipes.

| file | content |
|---|---|
| `gfi_all_condotte_acque_bianche.json` | storm-water pipes (GeoJSON) |
| `gfi_all_condotte_acque_nere.json` | sewer pipes (GeoJSON) |
| `gfi_all_punti_luce.json` | street lights |
| `wfs_*.json` | WFS layers of the same portal (cadastral streets, buildings) |

Attribution shown on the web page: "Comune di Savona SIT (CC BY 4.0)".
