## 2026-11-04 — Correction: monotone rule of the per-cell chance curve (prob_raster.lfdr_curve)
- Defect found while explaining the page raster: the local false discovery rate curve was made non-increasing by taking the
  running maximum from the top score bin downwards. In chunks where the channel-shuffled null has a sparse extreme tail
  (a few cells scoring above every observed cell), the top bins have lfdr = 1 and the running maximum set lfdr = 1 for the
  whole chunk. Measured: 51 of 195 raster chunks had no cell at P >= 0.5 for this reason (drive 36, 600-1200 m: observed
  cells with score >= 1.0 are 3.3 x the null's, yet all P were 0).
- Fix: lfdr per bin = min(1, f0/f) fitted by a count-weighted (observed cells per bin) decreasing isotonic regression
  (pool-adjacent-violators); empty observed bins take the value of the last filled bin below. Unit tests
  pipeline/tests/test_prob_raster.py (known answers: already-monotone unchanged; weighted pooling; sparse-tail chunk keeps
  lfdr 0.02 at the excess while the bulk stays at 1).
- Consequence: every P raster (E42 display product) and every test built on them (E45 Via Nizza, E46 regions, E47
  survey-wide, and the page's P layer and "seen from two lanes" lines) is provisional until recomputed with the corrected
  curve. The test statistics and pre-registered rules of E45-E47 are unchanged; only the per-cell P estimator is corrected.
